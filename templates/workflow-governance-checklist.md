# Workflow Governance Checklist

- [ ] Every workflow and automation has a named business owner
- [ ] No production workflow depends on a single personal account
- [ ] Connections and credentials are managed centrally
- [ ] Inventory of workflows kept current (purpose, owner, trigger, data touched)
- [ ] Personal data minimized, with retention and deletion rules applied
- [ ] Access reviewed periodically
- [ ] Changes go through requirements, testing, and release checks
- [ ] Failures are monitored and have an escalation path
- [ ] Human decision points documented for AI-assisted steps
- [ ] Documentation updated with every change
