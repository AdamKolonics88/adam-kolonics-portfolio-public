# Requirements Template

| Field | Content |
|---|---|
| Problem statement | What is not working today, for whom, and why it matters |
| Users and roles | Who uses the workflow and what each role may see and do |
| In scope | |
| Out of scope | |
| Workflow states | States, allowed transitions, and who can trigger each |
| Notifications | What is sent, to whom, and when |
| Data | Data collected, why it is needed, where it is stored |
| Privacy | Legal basis, retention period, deletion method |
| Access control | Least-privilege rules per role |
| Human decision points | Decisions that must stay with a person |
| Integrations | Systems read from or written to, and direction of data flow |
| Success measures | How the result will be measured |
| Owner and approver | Named owner for each decision |
