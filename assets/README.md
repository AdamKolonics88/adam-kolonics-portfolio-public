# Assets

This folder is intentionally empty of screenshots and exports.

Diagrams in this portfolio are written in Mermaid (see [`../diagrams/`](../diagrams/)) so that no
image from a private system, client environment, or internal tool is published. If an image is
added here in the future, it must be a newly drawn, generic illustration that contains no real
names, identifiers, URLs, data, or configuration.
