## How I Deliver

1. Agree on the problem, the users, and what "done" means before choosing tools.
2. Write requirements with scope, exclusions, and an owner for each decision.
3. Map workflow states, handoffs, and the decisions that stay with people.
4. Set access, retention, and deletion rules; where automation runs in production, plan for centrally managed service accounts rather than personal-account dependencies.
5. Test against a written plan and keep the evidence; check release readiness before go-live.
6. Document the system and hand it off so it does not depend on one person.

I use AI tools to speed up building. Requirements, test evidence, and release checks decide what ships.
